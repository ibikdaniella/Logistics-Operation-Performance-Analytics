Logistics Operations & Performance Analytics Dashboard

Project Overview

This project is a Logistics Operations & Performance Analytics Dashboard developed using Microsoft Power BI as part of a Data Analytics Capstone Project.

The dashboard analyzes logistics operations across customers, routes, drivers, trucks, fuel consumption, deliveries, revenue potential, and operational incidents.

The goal of the project is to transform raw logistics data into an interactive business intelligence solution that allows stakeholders to monitor operational performance, identify trends, and make data-driven decisions.

⸻

Project Objectives

The main objectives of this project were to:

* Analyze overall logistics operations and performance.
* Monitor revenue potential and fuel costs.
* Track delivery and on-time performance.
* Analyze customer activity and customer types.
* Evaluate driver and fleet performance.
* Monitor fuel consumption and distance traveled.
* Analyze truck utilization and status.
* Identify operational trends and potential areas for improvement.
* Present complex datasets through an interactive Power BI dashboard.

Dashboard Structure

The Power BI report consists of three major analytical pages.

1. Executive Overview

The Executive Overview provides a high-level summary of logistics operations.

Key Performance Indicators

* Total Routes
* Total Revenue Potential
* Total Fuel Cost
* On-Time Delivery %
* Total Distance
* Total Customers

Analysis Included

* Trips completed by month
* Revenue potential by customer type
* On-time delivery status
* Fuel cost trends
* Trips by primary freight type
* Operational details by destination, rate, incidents and trailer type

This page is designed to provide management with a quick overview of the organization’s overall logistics performance.

⸻

2. Customer Analysis

The Customer Analysis page focuses on customer activity, revenue potential and customer characteristics.

Key Performance Indicators

* Total Customers
* Active Customers
* Inactive Customers
* Total Revenue Potential
* Average Credit Terms
* Average Revenue Potential

Analysis Included

* Customer distribution by customer type
* Revenue potential by customer type
* Customers by primary freight type
* Fuel surcharge by account status
* Revenue trends over time

Interactive Filters

Users can filter the analysis using:

* Booking Type
* Load Type
* Customer ID

This page helps users understand the composition and financial contribution of the customer base.

⸻

3. Fleet & Driver Analysis:

The Fleet & Driver Analysis page focuses on transportation resources and operational efficiency.

Key Performance Indicators:

* Total Fuel Consumption
* Total Trips
* Number of Drivers
* Total Trucks
* Total Distance
* Average Trip Distance

Analysis Included:

* Trips completed by driver
* Distance trends over time
* Drivers by home terminal
* Fuel consumption over time
* Truck status distribution

Interactive Filters:

* Month
* Driver Name
* Model Year
* Tank Capacity

This page provides insights into driver activity, fleet availability, fuel usage and transportation performance.

Data Preparation:

The data preparation process involved:

1. Importing the source datasets into Power BI.
2. Reviewing the structure and quality of the data.
3. Transforming datasets using Power Query.
4. Ensuring appropriate data types.
5. Establishing relationships between relevant tables.
6. Creating calculated measures using DAX.
7. Developing KPIs for operational and financial performance.
8. Designing interactive visualizations.
9. Adding slicers and filters for dynamic analysis.
10. Organizing the report into three analytical pages.
